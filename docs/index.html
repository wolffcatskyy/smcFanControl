Cooling CE: development candidate

A C system controller, independent C watchdog, native CLI and Objective-C/AppKit menu app. System services are configured to start at boot; the interface is optional. Policies include automatic, minimum, manual, maximum and a single-sensor curve.

The candidate has been piloted on one MacPro6,1. A corrected automatic-to-maximum transition still needs its final physical test; cold boot before login, user switching, sleep/wake and other Intel models remain unverified. It is not a released replacement or a claim of commercial feature parity.

Install deliberately

Use one fan controller at a time, including boot helpers. Development builds are not notarized releases. Administrator installation changes system services; quitting or deleting the interface does not remove those services. Review the matching recovery guide before migrating.

Small footprint is a design goal. No controlled comparison establishes that this app is the smallest or fastest. Neither OCLP detection nor an installed helper guarantees cooling behavior or update compatibility.
